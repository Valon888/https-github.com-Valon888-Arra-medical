# Arra Medical

**Arra Medical** është një projekt web edukativ që simulon një faqe të një institucioni shëndetësor modern. Kjo faqe është krijuar për të demonstruar dizajnin, funksionalitetin dhe strukturën e një webfaqeje profesionale për një klinikë mjekësore.

## Përmbajtja

- **Ballina**: Prezantim i shkurtër i Arra Medical dhe shërbimeve kryesore.
- **Shërbimet**: Listë e detajuar e shërbimeve mjekësore që ofrohen.
- **Objektet**: Informacione për ambientet dhe pajisjet moderne të klinikës.
- **Rreth Nesh**: Prezantim i misionit dhe vizionit të institucionit.
- **Stafi mjekësor**: Prezantim i stafit kryesor mjekësor.
- **Pyetjet e Bëra Më Shpesh**: Përgjigje për pyetjet më të zakonshme të pacientëve.
- **Rezervo një vizitë**: Formular për rezervimin e vizitave.
- **Kontakt**: Formular kontakti dhe të dhëna për komunikim.

## Si ta përdorësh

1. **Hap skedarin `index.html`** në shfletuesin tënd për të parë faqen.
2. Të gjitha stilet janë në `style.css` dhe imazhet në dosjen `Arra Medical (2)`.

## Publikimi në GitHub Pages

- Sigurohu që skedari kryesor të quhet `index.html`.
- Ngarko të gjithë skedarët në një repository publik në GitHub.
- Aktivizo GitHub Pages nga Settings → Pages dhe zgjidh branch `main` dhe folder `/ (root)`.
- Faqja do të jetë e aksesueshme në:  
  `https://<username>.github.io/<emri-i-repository-t>`
